# スクリーンショット差し替えガイド

ランディングの機能セクションは、ここに置く実アプリ画面（PNG）を表示します。
画像が無い間は `ScreenshotFrame` が「画面名つきのプレースホルダ」を表示するので、
未配置でもサイトは崩れません。実装フェーズで `just dev` でアプリを起動し、
下表の画面をダークテーマのまま撮影して、**この同じファイル名**で置いてください。

## 撮影の方針

- **テーマ**: ダーク（アプリ既定）。ライトに切り替えない。
- **データ**: デモ用の**架空**の会議タイトル・話者名（実ユーザーの会議内容は写さない）。
- **未配布/モック機能を写さない**: 連携画面の Zoom/Meet 直接連携・参加者自動識別・Obsidian 自動同期などの「プレビュー」項目がフレームに入らない構図にする。
- **解像度**: Retina（@2x）で撮影。表示比は 16:10 想定。ウィンドウ幅は全画面で統一。
- **トリミング**: アプリ内のコンテンツ領域のみ（OS のメニューバー／デスクトップは含めない）。`ScreenshotFrame` 側でウィンドウのタイトルバー（信号機ドット）を描くので、**アプリ画面本体だけ**でよい。
- **形式**: PNG。

## 必要なファイル一覧

| ファイル名 | 撮る画面 | 構図のポイント |
|---|---|---|
| `detail.png` | 詳細ビュー（文字起こし＋要約・議事録＋右の話者パネル） | ヒーローにも使う最重要カット。話者チップ・要約・アクションアイテムが見える状態 |
| `meeting.png` | 会議モード（録音中のライブノート） | 経過時間・ライブ文字起こしの増分行が見える状態 |
| `speakers.png` | 話者照合（詳細の話者パネル or 話者ライブラリ） | 候補サジェスト or 登録済み話者の一覧が見える状態 |
| `history.png` | 履歴・全文検索（検索語ハイライト） | 検索ボックスに語が入り、`<mark>` ハイライトが出ている状態 |
| `integrations.png` | 連携（実機能：Notion/Slack/Google カレンダー） | **実機能のみ**。プレビュー項目を避ける |

> MCP セクションは Claude 側のUIを模した擬似チャットで表現するため、アプリ画面の撮影は不要です。

## 差し替え手順

1. `just dev` でアプリ起動（初回はモデルDLが走る）。
2. デモデータを用意し、各画面を上記ファイル名で `landing/public/screenshots/` に保存。
3. `landing/` で `npm run build && npm run preview` を実行し、各フレームに実画面が出ることを確認。
