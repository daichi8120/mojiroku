# 0002. デスクトップアプリ基盤に Tauri v2 を採用

- ステータス: 採用
- 日付: 2026-06-24

## Context

「基本無料・維持費 $0」の最重要制約から、サーバー推論を避けて**ユーザー端末でローカル推論**する必要がある。
配布形態の候補は (a) デスクトップアプリ、(b) ブラウザのみ（WASM/WebGPU）、(c) セルフホスト型 Web。
(c) は推論サーバーの維持費が発生し制約に反する。(b) は毎回数 GB のモデル DL と WebGPU 性能依存で
長時間音声・日本語 large-v3 が遅い。→ **デスクトップアプリ**が本命。

デスクトップ基盤は Electron と Tauri v2 が候補。Electron は Next.js 資産を活かせるが重い。
Tauri v2 は軽量シェルでバイナリが小さく、ネイティブ（Rust）と密に連携でき、本プロジェクトが
ローカル ML を Rust で駆動する方針（[ADR-0003](./ADR-0003_MLをRust単一ランタイムに集約.md)）と噛み合う。

## Decision

デスクトップ基盤に **Tauri v2** を採用する。

## Consequences

- ホスティング費 $0、ネイティブ高速化（Core ML/Metal）を活かせる。
- dev-hub 初の Rust 導入（習熟コストは受容。[requirements](../requirements.md) §7）。
- 要インストール・コード署名/公証が必要（[spec](../spec.md) §14）。
