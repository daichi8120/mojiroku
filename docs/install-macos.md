# macOS へのインストール

mojiroku は **Apple Developer ID で署名し、Apple の公証（notarization）を通して**配布しています（v0.4.0 以降、ADR-0022）。
ダウンロードしてそのまま開けます。Apple Silicon Mac（M1 以降）・macOS 11 以降が対象です。

> 公開向けの同じ手順はランディング（`mojiroku.com`）の「インストール（初回のみ）」にも載せています。
> ここは開発・リポジトリ参照用の控えです。

## 手順

1. **ダウンロードと配置**
   `mojiroku.com/download`（→ GitHub Releases の `.dmg`）を取得し、開いて `mojiroku.app` を
   「アプリケーション」フォルダにドラッグします。

2. **ダブルクリックで起動**
   署名・公証済みのため、「壊れているため開けません（damaged）」等の警告は表示されません。
   そのまま起動できます。

3. **初回起動**
   モデル（文字起こし/要約/VAD 用、合計で数 GB）が自動ダウンロードされます。録音をはじめるときに
   マイクの許可、会議モードの利用時に画面収録（システム音声）の許可を求められるので許可してください。

## 補足

- すべてローカルで動作します。音声・テキストは Mac の外に送信されません。
- アンインストールは `mojiroku.app` をゴミ箱へ。データは `~/Library/Application Support/com.daichi0812.mojiroku/` にあります。
- **v0.3.0 からアプリ内アップデートで更新した場合**: 署名の切替（未署名 → Developer ID）により、
  更新後の初回にマイク・画面収録の許可が**一度だけ**再度求められます。以後の更新では発生しません。

## 旧バージョン（v0.3.x 以前・未署名）を使う場合

v0.3.x 以前は未署名で配布していたため、ダウンロード（隔離属性付き）の初回起動が
「"mojiroku" is damaged and can't be opened（壊れているため開けません）」になります。
**ファイルは壊れていません**。ターミナルで隔離属性を外してから開きます：

```bash
xattr -dr com.apple.quarantine /Applications/mojiroku.app
```

- macOS 26 (Tahoe) の実機で、この "damaged" 表示 → 上記 `xattr` で起動できることを確認済み。
- 以前の「右クリック →『開く』」によるバイパスは macOS 26 で廃止されています。
- 代わりに「開発元を確認できません」と出た場合は、**システム設定 →「プライバシーとセキュリティ」**の
  **「このまま開く」**から起動できます。
